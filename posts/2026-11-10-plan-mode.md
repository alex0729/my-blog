## 한 줄 요약

플랜 모드는 **조사하고 계획만 세우고, 승인 전에는 소스를 고치지 않는** 모드다.

## 언제 쓰면 좋은가

- 여러 파일을 건드리는 큰 변경을 하기 전
- 처음 보는 코드베이스에서 구조부터 파악하고 싶을 때
- 무엇을 바꿀지 눈으로 확인하고 나서 맡기고 싶을 때

## 사용법

켜는 방법은 세 가지다.

| 방법 | 내용 |
|---|---|
| 단축키 | 세션 중 `Shift+Tab`을 상태 표시줄에 `⏸ plan mode on`이 보일 때까지 누른다 |
| 한 번만 | 프롬프트 앞에 `/plan`을 붙인다 |
| 처음부터 | CLI 옵션으로 시작한다 |

```bash
claude --permission-mode plan
```

프로젝트 기본값으로 쓰려면 `.claude/settings.json`에 넣는다.

```json
{
  "permissions": {
    "defaultMode": "plan"
  }
}
```

- 계획이 나오면 `Ctrl+G`로 기본 텍스트 에디터에서 직접 고칠 수 있다
- 승인하지 않고 나가려면 `Shift+Tab`을 다시 누른다

## 짧은 예시

```text
/plan 로그인 화면에 "비밀번호 보기" 버튼을 추가하고 싶어
```

계획이 준비되면 Claude가 어떻게 진행할지 묻는다.

| 선택지 | 결과 |
|---|---|
| Yes, and use auto mode | 승인하고 auto 모드로 편집 시작 |
| Yes, manually approve edits | 승인하고 편집을 하나씩 검토 |
| No, keep planning | 플랜 모드에 남아 계획을 고친다 |

> auto 모드를 쓸 수 없는 세션에서는 첫 선택지가 **Yes, auto-accept edits**로 보인다.

## 주의할 점

- 플랜 모드에서도 파일 읽기와 탐색용 셸 명령은 실행된다
- 읽기 전용이 아닌 명령은 환경에 따라 승인을 묻거나 분류기가 검토한다
- 승인하면 플랜 모드가 꺼지고 고른 권한 모드로 바뀐다. 다시 계획하려면 `Shift+Tab`이나 `/plan`을 쓴다
- VS Code 확장은 프로젝트 설정의 시작 모드를 읽지 않는다. VS Code 사용자 설정의 `claudeCode.initialPermissionMode`를 `plan`으로 둔다
