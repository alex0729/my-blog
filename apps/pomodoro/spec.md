# 뽀모도로 타이머 — spec

## 1. 한 줄 요약
- 집중 25분 ↔ 휴식 5분을 번갈아 세는 네온 톤 타이머. 파일 1개, 라이브러리 없음, iframe 카드에 그대로 들어감

## 2. 기능

**넣는 것**

| 기능 | 내용 |
|---|---|
| 시작 / 일시정지 | 버튼 1개. 누를 때마다 전환 |
| 리셋 | 현재 단계를 처음 시간으로, 정지 상태로 |
| 단계 자동 전환 | 집중 끝 → 휴식, 휴식 끝 → 집중. 전환 후 **정지 상태**로 대기 |
| 종료 알림 | 짧은 비프음 + 탭 제목 변경 |
| 남은 시간 탭 제목 | `12:34 · 집중` 형태로 `document.title` 갱신 |
| 테스트용 빠른 모드 | URL `?fast` → 집중 5초 / 휴식 3초 (Review 검증용, 화면에 노출 안 함) |

**제외한 것** (요청에 없음)
- 긴 휴식(4회마다 15분)
- 시간 설정 UI (분 입력·슬라이더)
- 완료 횟수 카운터·통계·기록
- 단계 건너뛰기 버튼
- 브라우저 Notification API (권한 팝업, iframe 안에서 제한)
- 진동(`navigator.vibrate`)
- 새로고침 후 상태 복원(`localStorage`)
- 키보드 단축키 (버튼 포커스+Space/Enter로 충분)
- 할 일 목록, 테마 전환, 소리 선택
- 진행 링·프로그레스 바 애니메이션

## 3. 화면 구성

```
┌──────────────────────────────┐
│            집 중              │  ← 단계 라벨 (집중=pink / 휴식=cyan)
│                              │
│          24:59               │  ← 남은 시간, 크게, 글로우
│                              │
│   [ 시작 ]      [ 리셋 ]      │  ← 버튼 2개, 각 44px 이상
└──────────────────────────────┘
```

- 한 열, 세로·가로 가운데 정렬. 스크롤 없음
- 시간 글자 크기: `min(22vw, 32vh)` 수준 → 폭·높이 둘 다 작아도 맞춰 줄어듦
- 최소 보장 크기: **320×200px** (iframe 카드) / 375px 폭 모바일
- 높이 240px 미만: 라벨·버튼 간격만 줄임 (요소는 숨기지 않음)

## 4. 동작 규칙

| 항목 | 규칙 |
|---|---|
| 시간 | 집중 25분, 휴식 5분. 스크립트 맨 위 상수 2개 |
| 사이클 | 집중 → 휴식 → 집중 … 무한 반복. 첫 화면은 `집중 25:00` 정지 |
| 단계 끝 | 비프 → 다음 단계로 바꾸고 정지. 사용자가 다시 시작 |
| 시간 계산 | 시작 시 `endAt = Date.now() + 남은ms` 저장. 매 tick 마다 `endAt - Date.now()`로 다시 계산 (카운트다운 누적 X) |
| tick | `setInterval` 250ms. 표시는 초 단위 올림(`Math.ceil`) |
| 일시정지 | `남은ms = endAt - Date.now()` 저장, interval 해제 |
| 백그라운드 탭 | 브라우저가 타이머를 느리게 해도(1초~최대 1분) 표시는 `endAt` 기준이라 틀어지지 않음. `visibilitychange`로 돌아올 때 즉시 재계산 |
| 백그라운드 알림 정확도 | 시작 시 Web Audio 오실레이터를 `ctx.currentTime + 남은초`에 **예약 재생** → 타이머 지연과 무관하게 제때 울림. 일시정지·리셋 시 예약 취소 |
| 오디오 잠금 | `AudioContext`는 첫 시작 버튼 클릭 때 생성·`resume()` (자동재생 정책 대응) |
| 끝난 뒤 표시 | tick이 늦게 와도 0 미만 표시 금지 → 0에서 다음 단계 전환 1회만 |
| 탭 제목 | 실행 중 `MM:SS · 집중`, 끝나면 `끝! · 휴식 시작` 식, 리셋하면 기본 제목 |

## 5. 파일 구조

```
apps/pomodoro/
├── index.html   # HTML + <style> + <script> 전부 인라인 (자체 완결)
├── spec.md      # 이 문서
└── review.md    # Review 단계에서 생성
```

- 앱 코드는 `index.html` 1개. 블로그 `static/style.css` 참조 안 함 → 필요한 변수만 `<style>`에 복사
- 소리 파일 없음 (Web Audio로 생성)
- `<html lang="ko">`, viewport meta 포함

## 6. 디자인

**쓸 색 (블로그 `static/style.css`에서 복사)**

| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#000000` | 배경 |
| `--fg` | `#c9f8ff` | 버튼 글자 |
| `--muted` | `#8b93c9` | 보조 텍스트 (정지 상태 라벨 등) |
| `--pink` | `#ff3ea5` | 집중 단계: 라벨·시간·버튼 테두리 |
| `--cyan` | `#3ef4ff` | 휴식 단계: 라벨·시간·버튼 테두리 |
| `--yellow` | `#ffe14d` | `:focus-visible` 외곽선 |
| `--line` | `#3ef4ff4d` | 리셋 버튼 테두리 |
| `--glow-pink` / `--glow-cyan` | 블로그 값 그대로 | 시간 숫자 글로우만 |

- 단계 색 전환: `<body data-phase="focus|break">` + CSS 변수 1개(`--accent`) 교체
- 숫자: `font-variant-numeric: tabular-nums` (자리 흔들림 방지)
- 폰트: 블로그와 같은 시스템 스택. 웹폰트 없음

**접근성**

| 항목 | 기준 |
|---|---|
| 대비 | pink 약 6.5:1, cyan·muted 7:1 이상 (검정 배경, AA 통과) |
| `:focus-visible` | `2px solid var(--yellow)`, offset 3px (블로그와 동일) |
| `prefers-reduced-motion` | 실행 중 깜빡임·전환 효과 없음. 글로우는 정적이라 유지 |
| 스크린리더 | 시간 요소는 매초 읽지 않음(`aria-live` 없음). 단계 라벨에 `aria-live="polite"` → 전환만 알림 |
| 버튼 | 실제 `<button>`. 시작/일시정지 글자 자체가 바뀜 (`aria-pressed` 대신) |
| 터치 | 버튼 최소 44×44px |

## 7. Review 체크리스트

- [ ] `index.html` 1개로 동작, 외부 요청 0건 (네트워크 탭)
- [ ] 콘솔 에러 0
- [ ] 시작 / 일시정지 / 재개 / 리셋 정상
- [ ] `?fast`로 집중→휴식→집중 전환 확인, 전환 후 정지 상태
- [ ] 단계 끝 비프음 1회, 탭 제목 변경
- [ ] 백그라운드 탭에서 끝나도 비프가 제때 울림 (`?fast` + 다른 탭 이동)
- [ ] 일시정지·리셋 후 예약된 비프가 울리지 않음
- [ ] 다른 탭 갔다 오면 표시 시간이 실제 경과와 일치
- [ ] 0 아래로 내려가거나 전환이 2번 일어나지 않음
- [ ] 375px 폭: 가로 스크롤 없음, 버튼 44px 이상
- [ ] 320×200 iframe: 잘림·스크롤 없음
- [ ] 키보드만으로 조작 가능, 포커스 노란 외곽선 보임
- [ ] `prefers-reduced-motion` 에뮬레이션에서 움직임 없음
- [ ] 집중=pink / 휴식=cyan 색 전환
- [ ] 블로그 파일(`static/`, `build.js`, `posts/`) 변경 없음
