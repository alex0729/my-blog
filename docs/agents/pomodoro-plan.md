# Plan 서브에이전트 지침 — 뽀모도로 타이머

## 역할
웹앱 계획만 작성한다. **코드를 작성하지 않는다.**

## 수정 범위 (이 파일만 생성)
- `apps/pomodoro/spec.md` — 새로 만든다
- 그 외 파일은 읽기만 한다. 생성·수정·삭제 금지

## 먼저 읽을 것
- `CLAUDE.md` — 작업 사이클 · 웹앱 규칙 · 디자인 기준(6절)
- `static/style.css` — 블로그 네온 색 변수 (웹앱도 같은 톤을 쓰되, `apps/pomodoro/` 안에 자체 CSS로 복사해 자체 완결)

## 요구사항
- 사용자 요청: "뽀모도로 타이머 웹앱"
- HTML, CSS, JavaScript만. 외부 라이브러리 없이 가능하면 쓰지 않는다 (CDN은 허용되지만 필요할 때만)
- `/apps/pomodoro/` 안에서 자체 완결. 블로그 파일에 의존하지 않는다
- 모바일 사용 가능 (375px 폭, 터치 대상 44px 이상)
- 블로그 메인 카드에 iframe으로 넣을 수 있어야 한다 (작은 높이에서도 깨지지 않게)
- 최소 기능 우선. 요청에 없는 기능은 "제외한 것" 목록에 적고 넣지 않는다

## spec.md에 담을 것 (짧게, 불릿·표 위주, 한국어)
1. 한 줄 요약
2. 기능 목록 (꼭 필요한 것만) + 제외한 것
3. 화면 구성 (ASCII 스케치 1개)
4. 동작 규칙 (집중/휴식 시간, 사이클, 탭이 백그라운드일 때 시간 정확도 처리 방식, 끝났을 때 알림 방식)
5. 파일 구조 (`apps/pomodoro/` 트리) — 파일 수 최소
6. 디자인 (블로그 네온 변수 중 쓸 색, 접근성: 대비·`prefers-reduced-motion`·`:focus-visible`)
7. Review 단계에서 확인할 항목 (체크리스트)
8. 열린 질문 (사용자가 정해야 할 것, 있으면)

spec.md 맨 앞에 YAML frontmatter: `date: 2026-11-13`, `title`, `source`(사용자 요청 근거), `tags`(4~5개 inline list).

## 끝나면
spec.md 경로와 열린 질문만 짧게 보고한다.
